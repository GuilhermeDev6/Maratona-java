## ORGANIZAÇÃO DO CÓDIGO E ATALHOS DA IDE

### Pacotes

 - Todas as classes devem ser criados em pacotes (pastas organizaddoras)

### Atalhos úteis (IntelliJ)

- PSVM: Cria automaticamente o método principal de execução do Java: public voind main(String [] args){}
- SOUT: Cria a instrução que chama o método de exibir dados no console: System.out.println();
- FORI: Monta a estrutura completa de um laço FOR

## VARIÁVEIS E TIPOS DE DADOS

### Regra de nomenclatura (cameCase)  

- A primeira do nome da variável deve ser minúscula. Se for uma palavra composta, as palavras seguintes começam com letra maiúscula: anoNascimento
